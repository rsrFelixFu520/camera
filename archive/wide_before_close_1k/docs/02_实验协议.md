# v5 实验协议、数据域和可验证范围

## 1. 实验对象与单变量定义

本次使用 Isaac Sim `6.2.0-rc.14+release.52805.02189a84.gl`，在独立进程与 GPU 1 上采集；没有接管其他项目的 Isaac 进程。场景引用安装目录中的 `Isaac/Environments/Simple_Room/simple_room.usd`，将房间上移 0.77 m，使原有桌面约在世界 z=0.78 m。

来自用户目录的十个 GLB 通过 Omni asset converter 保留材质/纹理转换为 USD，随后按包围盒等比缩放、底面归零并摆上原有桌子。物品摆放和尺寸为实验设定，见 [资产转换](../analysis/asset_conversion.json) 与 [摆放记录](../analysis/scene_layout.json)。没有把真实照片贴到场景中。

“一个变量”指一个逻辑标量或模式，例如焦距、曝光时间、一个 CCM 系数、扫描方向。其余参数采用基准，必要的固定上下文在该组全部档位保持一致。例如对焦距离组固定 fStop=1；景深光圈组固定 focusDistance=2.2 m，曝光光圈仍为 5。分辨率变化所必需的实际 buffer 尺寸变化是同一逻辑控制的实现，不算另一个独立自变量。

每组 2～3 档，每档 5 帧。开关和双模式参数只有两档，未虚构第三档。原生档位采用固定种子打乱顺序，参数更新后默认预热 16 次 app update，再洗出 3 次、每次 4 render subframes；warm-up 与 subframes 本身作为变量时按相应协议。五个重复是连续的新渲染调用，不是同图复制，但不据此宣称统计上完全独立。

## 2. 三层图像生成路径

### A. Isaac 原生扫描

```text
Simple Room + 用户模型 + 固定靶
→ USD camera / light / material / RTX RenderProduct 参数
→ 实际 RTX 渲染
→ 原始 RGB8 annotator 字节
→ 固定、显式的 sRGB OETF 预览
```

每帧保存 `config`、逻辑变化、时间、相机运行时投影、相机属性、RenderProduct 属性、图像尺寸和像素 SHA256。原始图为 `renderer_*.png`，预览为 `frame_*.png`。RGB8 是本管线的 renderer 输出，不能仅凭文件后缀把它称为实机 RAW。

本机默认 pinhole 确实保持方形像素：G03 的三个 verticalAperture 档位，运行时 fx、fy 都约为 740 px。应以 camera_params 与图像响应为证据，不能认为 USD 声明的 verticalAperture 一定独立改变 fy。D02 则使用 OpenCV lens schema 单独控制 fy。

`exposure` EV 的此次输出没有呈现理想补偿倍率，保留原图和读回；`exposure:time/iso/fStop/responsivity` 的响应分开扫描。对“声明了但未出现预期变化”的参数，不用后处理伪装成已获原生支持。相机曝光属性与 tone operator 的具体行为需以此安装版为准。[OpenUSD / RTX 相机说明](https://docs-prod.omniverse.nvidia.com/materials-and-rendering/latest/cameras.html)

### B. 假设的电子—CFA—ISP 模型

```text
五次实际 Isaac HdrColor 静态辐射输入（640×480、float16）
→ RGB 域光学空间近似、通光
→ 光子标尺 × scalar QE
→ PRNU / 暗电流 / DSNU / Poisson
→ full-well 截断
→ 读噪 / 行列噪声 / 模拟增益
→ ADC 与黑位 / 可选 companding round-trip
→ CFA 采样 / BLC / 坏点与 RAW 域处理 / LSC
→ demosaic / WB / CCM / 降噪 / 锐化 / 色调与颜色处理
→ 明确的显示编码 / 输出重采样 / YUV / 量化 / codec
```

这里的噪声先在电子/ADC 域产生，并非最后对显示 RGB 随意撒颗粒。但输入仍然是**三通道 renderer linear RGB**，没有实际传感器光谱响应，也没有绝对辐射标定；完整 RGB 到 CFA 前的光子数量标尺是设定值，不能当作实测入射光子数。

默认：一单位辐射在 20 ms 下对应 16000 photons，QE=0.5，full well=8000 e−，white reference=8000 e−，读噪=3 e− RMS，ADC=12bit，黑位与 BLC 均为 12bit DN=64。固定图样 seed=57001，各重复的随机 seed=58000+repeat。档位共享随机数以降低蒙特卡洛差异，五个重复使用不同时间 seed；这是一种模型比较设计，不是声称实机噪声分布已经被验证。

温度组使用“每升高 8 K 暗电流翻倍”的**演示假设**。PSF、衍射、色差、flare、ghost、bloom 为显式 RGB 空间近似，不能认证真实镜片。CFA/去马赛克经过常量颜色检验，防止 RGGB/BGGR 代码含义写反。所有九个 CCM 系数分别扫描，不随档位进行隐藏归一化。

binning 演示在已有图像上做 average / sum / subsample，不等于真实电荷域 binning；OLPF 演示只能影响本次进一步降采样，不能恢复早期已混叠内容。HDR/companding/AE/AWB 都是公开的可执行演示模型，不是 AVS 专有固件逆向。

### C. 时间模型

先实际渲染 97 个已知物体位置，世界状态间隔 1/240 s，靶标沿 X 以 2.6 m/s 移动。每个状态渲染两次以洗出异步变换，再保留 HdrColor。然后在这些实际渲染的辐射图之间插值，以 midpoint quadrature 执行曝光积分，逐行改变曝光中心实现 rolling shutter；没有拿一张图片做剪切就称作真实 rolling shutter。

该方法的时间分辨率受 240 Hz 状态采样限制，遮挡切换和亚采样运动只是近似；不能推广为 RTX 原生 rolling-shutter 能力。运动曝光窗口最长 1/15 s，在数据时间范围内积分。FPS/丢重帧用四个时刻的 filmstrip；延迟组比较固定使用时刻下收到的旧图，而已曝光图本身不会被网络延迟改变。时间戳 start/center/end 组仅改标签，像素保持一致，正确地演示“元数据变化不一定改变图像”。

时间模型使用同一段实际渲染的运动序列。没有随机输入的组，五次模型运行输出相同，不能当作五次独立动态采集来估计置信区间。读出跨度高档为 240 ms，用于放大可见形变，并非 AVS 工作模式；扫描方向组也固定为这个演示跨度。

AE/AWB 组使用 24 步阶跃刺激，输出第 5、7、12、23 步的 2×2 filmstrip，并保存每步曝光、增益、WB、均值。曝光与增益分配组可能得到相近静态亮度，但轨迹中的设置不同；该控制器没有模拟真实固件带来的噪声与拖影差异。

## 3. 数值如何解释

| 本次数值 | 说明 | 不应声称 |
|---|---|---|
| 全图显示 RGB 均值及其 5 帧标准差 | 当前处理输出的明暗响应与帧间漂移 | 线性辐射校准结果 |
| 逐像素跨重复的标准差均值 | 本管线的时间变化，包含渲染器历史和模型噪声 | 实机 sensor temporal noise、EMVA 1288 结果 |
| 高/低码值比例 | 接近输出上下界的像素占比 | ADC 满阱或完整动态范围已测得 |
| Laplacian RMS | 图像高频/边缘响应的辅助描述 | MTF50、ISO 12233 结果 |
| 档位均图差、差值热图 | 同一实验中参数造成的输出差 | 异内容真实—仿真一致性分数 |
| SEDD | 固定网络与抽样下的数据集风格距离 | 所有物理参数已经一致 |

固定 ROI 是在均图档位差中选择一个响应较强的位置，再对全部档位使用同一坐标；这有利于看清影响，**不是预注册计量 ROI**。它没有用于制造真实/仿真合格结论。主图的 sRGB 预览、JPEG 对比板及热图只用于浏览，数值统计读取逐帧无损原图。

## 4. 未完成的真实测量和不可见参数

- 逐波长 SPD、材料光谱反射/透射、QE/CFA/IR-cut 光谱曲线、同色异谱：本 RGB 场景不具备可验证数据。
- 真实 pixel pitch、模拟链路、AVS 的完整 PSF/噪声/AE/AWB/HDR 参数、快门读出时序：缺实测，不能从自然图补造。
- HDRI 的方向纹理、实机完整 BSDF/normal map、真实镜片 ghost/flare：只覆盖其中部分或现象近似。
- 六路相机真实物理选目、头部历史标号冲突、机器人状态同步/手眼/关节：新实验室位置没有替它们完成验收。
- 几何靶、色卡、灰阶、斜边、暗/平场和已知运动输入：本次构造了仿真侧学习靶，尚未新增真实采集。

因此本次交付的是“论文候选指标 + 可审计的参数响应实验包”，真实相机物理一致性总状态仍为 `NOT_EVALUATED`。

## 5. 资源异常与批次

第一批原生组在反复创建/销毁 RenderProduct 后触发 RTX resource-descriptor 耗尽，已停止本实验进程，保留完成组，并改为按分辨率复用产品后续采。没有重启其他项目进程。最初 pilot 的元数据在正式扫描开始时被替换，正式结果只收录每个档位完整的 5 帧；错误与恢复过程留在日志，避免把失败采集当成功。

跨组批次和渲染器的内部缓存/历史可能不同，原生重复主要用于观察波动；不能仅由“五帧”推断达到精密统计置信度。后续正式量化标定应采用预注册 ROI、重复批次、反复交错基准、更多独立场景与真实端重复性测量。
