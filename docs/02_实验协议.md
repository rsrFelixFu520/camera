# 近景 1K 光线追踪实验协议

本批次将主相机放在世界坐标 `(0.75,-1.35,1.85)` m，朝向 `(0,0,0.96)` m，光心到观察点约 1.78 m。旧版约 2.9 m，物品占画面比例更大。旧结果和旧脚本保留在 `archive/wide_before_close_1k/`，两批不能混成同一组控制变量实验。

## 分辨率与追踪设置

实际基准、静态/运动 HdrColor 输入与六路演示产品均为 **1024×1024**，没有将旧低分辨率图放大冒充新采集。R08 专门研究分辨率，故采集 512/1024/1536 方图；resize、crop、binning、overscan 等输出实验按定义改变最终尺寸。拼图是排版产物，单图原尺寸链接随每组提供。

- 基准及模型辐射输入：RTX PathTracing，64SPP，每子帧16SPP，6次反弹，渲染去噪开启。
- 主扫描默认：RTX PathTracing，32SPP，每子帧最多32SPP，6次反弹，渲染去噪开启。参数更新后默认2次 app update，加1次洗出采集，然后记录5次输出。
- R03 单独扫描8/32/128SPP，R04/R05/R06/R07分别扫描反弹、去噪、预热、子帧。
- R02/R10固定 RTX RayTracedLighting 测试该路径的 AA/漫反射反弹，R09比较实时RTX与PathTracing。二者均为光线追踪。

本批次驱动为570.172.18。R02的DLSS日志明确记录：Responsive Denoising要求R580及以上，当前回退到preset D。因此图片反映本机实际路径，不解释成该特性的最高配置结果。

R02/R09/R10共35帧请求`RayTracedLighting`，正式采集时实际读回`RealTimePathTracing`；本机Kit设置界面源码将其标为RTX Real-Time 2.0。其余960帧实际读回PathTracing。保留原始写入和读回，不把两种实时后端宣称为等价；R10的旧`indirectDiffuse/maxBounces`在RT2中是否生效未获证明。

SPP 是配置预算，不是独立硬件计数器实测的光线条数。Replicator 按 totalSpp/spp 安排PT子帧；逐帧保存实际设置读回。历史、缓存、去噪和量化可能让静态输出高度相关，五次输出不能直接当作五个独立传感器噪声样本。

## 单变量、原图与说明

每组只改变一个逻辑参数，2～3档，每档5帧/次模型运行。开关只有两档，固定上下文在同组各档一致。对焦组固定景深光圈fStop=1；景深光圈组固定focusDistance=1.5m，曝光光圈仍为5。

原生五帧来自连续的正式渲染调用；已收敛或确定性的管线可能输出完全相同的像素。它们没有被证明是五个独立随机样本，不能据此估计真实传感器噪声。

每项均附“是什么、影响什么/变化方向、看图位置”。主文档和浏览器按镜头、传感器、ISP、时间、输出等环节排列，而不是让读者从参数名猜现象。

原生路径为：实际场景 → RTX光追 → 原始RGB8（renderer_*.png）→ 固定sRGB OETF预览（frame_*.png）。保存尺寸、像素SHA256、配置、逻辑变化、相机/RenderProduct属性、camera_params与renderer读回。HdrColor是renderer linear RGB，不是sensor RAW。一个4×4矩阵或legacy pinhole标签不能单独认证后级fisheye/Brown畸变。

## 电子、CFA与ISP模型

输入是新采集的五帧1K静态辐射图。顺序为RGB空间光学近似/通光 → 假设光子标尺/QE → 固定图样/暗电流/Poisson → 满阱截断/读噪/模拟增益 → ADC/黑位/可选companding → CFA/BLC/DPC/RAW平滑/LSC → demosaic/WB/CCM/降噪/锐化/曲线 → 显示编码/重采样/YUV/量化/codec。

默认20ms下每单位辐射对应16000 photons、QE=0.5、full well=8000e−、white reference=8000e−、读噪=3e−、ADC=12bit、黑位/BLC=64（12bit DN）。它们是教学假设，没有AVS实测或绝对辐射标定来源。固定图样seed=57001，时间噪声seed=58000+repeat；不同档位共享随机数以降低比较干扰。

温度关系、PSF、衍射、色差、flare、ghost等是明确的近似。P08分别在1024原图、或先缩为768的图上使用相同数字ROI `[128:640,128:640]`，用于说明顺序与坐标所属阶段。binning不是电荷域实现，OLPF不能恢复输入中已经混叠的信息。

## 时间和自动控制

以1/240s间隔实际渲染97个状态，红靶沿X以2.6m/s移动，保存1K HdrColor；再通过插值和midpoint quadrature实现曝光积分与逐行选时。时间精度受240Hz网格限制，不能冒充原生RTX rolling shutter或实机时序验证。240ms读出跨度用于放大观察，不代表AVS模式。

确定性时间组复用同一段运动序列，五次模型输出可能相同，不是五次独立动态采集。AE/AWB使用24步演示控制器，四格显示第5、7、12、23步，曝光、增益、WB轨迹单独保存。相近静态亮度不意味着曝光/增益分配相同。

## 数值解释与边界

显示均值、边缘Laplacian RMS、码值上下界比例及档位均图差用于描述参数响应，不能当作MTF50、EMVA1288、动态范围或实仿物理一致性合格分数。重复帧逐像素标准差同时包含渲染历史与模型噪声，不是AVS时间噪声。

对比板保持长宽比，全部档位使用同一个1K坐标ROI；ROI按均图响应较强的位置选择，供教学观察，未当作预注册计量ROI。统计使用无损原PNG；JPEG拼板仅供浏览，细节应打开原尺寸图。

真实相机总体一致性仍为NOT_EVALUATED。完整光谱、IR-cut、真实镜片和AVS专有固件未由RGB模型验证。六路图是1K实验室观察模式，源K/D与安装合同另存；腕部原生幅面与1K方图不同，不未经靶点验证就声称模式等价。
