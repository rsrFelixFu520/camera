# 参数解释与看图指南

本表与近景 1024×1024 RTX 光追批次一致。点击 ID 可进入完整图文报告；每项都有独立参数解释，而不是只列扫描数值。

真实曝光时间同时影响 E01 的亮度、S20 的电子/噪声与 T01 的运动积分；真实光圈同时关联 E03 通光、O02 景深和 Q05 衍射。此处为了观察各作用而分开实验，不代表真实相机有这些彼此独立的硬件旋钮。

## 场景与照明

先决定物体送给镜头什么光。灯光、材质与相机响应应分开理解；调曝光不能替代正确的照明和反射。

| ID / 参数 | 它是什么 | 改变后影响什么 | 看图位置 |
|---|---|---|---|---|
| [L01 主光强度](../real_sim_camera.md#L01) | 主光源的强度参数，控制输入场景的光。 | 增大通常使受照表面更亮、高光更易饱和；阴影变化取决于补光与反射。 | 看白盘、灰块、高光和阴影，不能只看水果颜色。 |
| [L02 灯光 exposure](../real_sim_camera.md#L02) | 用 stop 表达的灯光强度倍率。 | 每增加 1 stop，灯的发光标尺乘 2；显示 RGB 经曲线和截断后不一定也翻倍。 | 比较灰阶块和白盘的亮度，检查高端灰块是否合并。 |
| [L03 主光 CCT](../real_sim_camera.md#L03) | 光源相关色温；改变照射场景的光色。 | 在 WB 固定时，低色温通常偏暖、高色温偏冷；相同 CCT 仍不代表完整光谱相同。 | 先看中性灰块和白盘，再看香蕉、甜椒的颜色变化。 |
| [L04 主光 X 位置](../real_sim_camera.md#L04) | 主光源在世界 X 方向的位置。 | 光源横向移动会改变受光面、高光位置和阴影方向，即使曝光没变也会有明暗变化。 | 看灰立方体的亮面和投影、瓶子上的高光。 |
| [L05 主光 Z 位置](../real_sim_camera.md#L05) | 主光源的高度。 | 改变高度会改变光线入射角、距离衰减与光源角尺寸，因此亮度和阴影软硬都可能变化。 | 比较灰块阴影长度、盘底阴影和高光面积。 |
| [L06 发光面宽度](../real_sim_camera.md#L06) | 矩形发光面的宽度。 | 变宽通常使横向阴影过渡更软；本组固定 intensity 而非总通量，整体亮度也可能变化。 | 看灰块、壶和瓶子投影的边缘，不把所有变化归因于柔光。 |
| [L07 发光面高度](../real_sim_camera.md#L07) | 矩形发光面的高度。 | 变高通常改变另一方向的光源角尺寸与半影，也可能增加总输出。 | 比较物体阴影的过渡宽度和盘面高光形状。 |
| [L08 主光倾角](../real_sim_camera.md#L08) | 主光源绕固定轴的倾斜角。 | 改变照射方向和有效投影面积，会同时改变受光面、阴影和高光。 | 看瓶子、壶侧面亮暗如何转换及投影偏向。 |
| [L09 环境补光](../real_sim_camera.md#L09) | 环境 Dome 补光的强度。 | 若环境光能到达物体，增大可抬高阴影、降低反差；封闭房间里可能被遮挡而影响很弱。 | 优先看盘底和物体背光面，微小差异不能当作普遍无效。 |
| [M01 中性物体漫反射率](../real_sim_camera.md#M01) | 物体漫反射的中性反射参数。 | 固定照明时，数值增大通常使灰探针更亮；不会让所有物体同时变亮。 | 只比较左侧灰立方体及其反射影响，别把它当相机曝光。 |
| [M02 表面粗糙度](../real_sim_camera.md#M02) | 表面微结构的粗糙程度。 | 小值通常产生较窄、较集中的高光或反射；大值让高光更宽、更模糊。 | 看灰立方体反光的形状与边界，而非只看平均亮度。 |
| [M03 金属度](../real_sim_camera.md#M03) | PBR 中金属与非金属反射行为的混合系数。 | 增大使表面更偏金属反射、漫反射减少，环境和光源反射更重要；不是统一增亮开关。 | 看灰探针是否更像反光金属，注意颜色和明暗分布。 |
| [M04 折射率输入 IOR](../real_sim_camera.md#M04) | 材质的折射率输入，影响界面反射/折射关系。 | 在当前材质工作流支持时会改变菲涅耳反射；不透明、无透射路径时不保证出现明显玻璃形变。 | 只看探针的边缘反射，不能把不明显的结果当成完整玻璃验证。 |
| [M05 透明度 opacity](../real_sim_camera.md#M05) | 表面的不透明程度，1 表示不透明。 | 减小会让后面的内容透出或减少遮挡；这是当前材质透明模型，不是相机曝光。 | 看灰探针背后的桌面能否透出，比较其投影与轮廓。 |
| [M06 镜面反射系数](../real_sim_camera.md#M06) | 非金属 specular workflow 的镜面反射颜色系数。 | 增大通常增强表面高光和环境反射；漫反射与总亮度的变化依材质实现而定。 | 在灰探针上找高光与反射，不只看水果。 |
| [M07 表面法线扰动](../real_sim_camera.md#M07) | 表面用于着色的法线方向扰动。 | 改变法线会改变受光、高光和反射方向；几何轮廓本身应基本不变。 | 看灰探针亮面变化，同时确认外轮廓没有像真实几何那样移动。 |
## 镜头：投影、畸变与安装

## 镜头：清晰度与光学外观

这一组决定细节如何被摊开、边缘是否分色、四角是否变暗，以及强光是否产生雾幕或光斑。

| ID / 参数 | 它是什么 | 改变后影响什么 | 看图位置 |
|---|---|---|---|---|
| [O01 对焦距离](../real_sim_camera.md#O01) | 相机设定的对焦距离，即最清晰的目标距离。 | 焦点移近会优先让近物清楚、远物变糊，移远时相反；只有开启景深后才应明显。 | 比较前景黑白靶、盘沿与后方斜边，不只看整图均值。 |
| [O02 景深光圈 fStop](../real_sim_camera.md#O02) | 控制景深的几何 f-number，数值越小孔径越大。 | 小 f-number 通常景深浅、焦外模糊强；大值通常更多距离清楚。本组曝光光圈固定，亮度不应被连带调节。 | 同时比较前景靶和远处色卡边缘的清晰度。 |
| [Q01 光学 PSF 宽度](../real_sim_camera.md#Q01) | 点扩散函数的高斯宽度近似，表示一个点被摊开多少像素。 | sigma 增大会让细线和边缘更糊、局部细节反差下降；与运动模糊的方向性不同。 | 放大刀刃、瓶身文字、斜边和条纹。 |
| [Q02 暗角强度](../real_sim_camera.md#Q02) | 镜头暗角的中心到边缘衰减强度。 | 增大使边缘相对中心变暗；它不是整图同时调暗。 | 比较靠角落的桌面与中心灰块，注意空间分布。 |
| [Q03 红通道颜色阴影](../real_sim_camera.md#Q03) | 只对红通道施加的空间阴影。 | 增大会让边角相对缺红、出现空间色偏，全局 WB 通常不能同时修好中心和四角。 | 比较白盘、灰桌面从中心到边缘的颜色。 |
| [Q04 红通道径向色差](../real_sim_camera.md#Q04) | 红通道的径向空间偏移近似。 | 增大后不同颜色边缘不能完全重合，尤其画面边缘容易出现红/青彩边。 | 看斜边、盘沿和黑白靶的边缘，不只看均匀色块。 |
| [Q05 衍射 f-number](../real_sim_camera.md#Q05) | 用于衍射近似的 f-number，固定假设波长与像元尺寸。 | 数值变大时衍射斑通常变宽，细节反差下降；这是衍射单独模型，与景深增大的收益分开。 | 看细条纹和斜边，阅读该组的波长/pixel-pitch 假设。 |
| [Q06 PSF 横向像散近似](../real_sim_camera.md#Q06) | 横向比纵向更宽的 PSF 简化。 | 增大使横向细节更糊，水平/垂直结构受影响不一样；不是全视场实测像散。 | 对比细竖条和水平边缘的清晰度。 |
| [Q07 杂散光雾幕](../real_sim_camera.md#Q07) | 给图像加入的线性雾幕光近似。 | 增大会抬高暗部、降低对比，让黑色发灰、颜色变淡；不同于简单提高曝光。 | 看黑白靶黑面与阴影，白处可能也更容易截断。 |
| [Q08 鬼影强度](../real_sim_camera.md#Q08) | 离散鬼影光斑的强度近似。 | 增大会出现更明显的额外有色光斑；这里没有追踪真实镜片多次反射路径。 | 看画面固定位置的半透明光斑，勿把它认成场景中的物体。 |
| [Q09 数字 bloom 强度](../real_sim_camera.md#Q09) | 高亮区域经模糊扩散后叠加的数字效果。 | 增大会让亮部向周围扩散、形成光晕；这种后处理不等于传感器溢出或真实镜头杂散光。 | 看白盘、高光附近是否侵入邻近暗区域。 |
| [Q10 降采样前低通](../real_sim_camera.md#Q10) | 在进一步采样前施加的低通滤波宽度。 | 增大可以减少后续采样的高频混叠，也会损失真实细节；无法消除输入里早已折叠的混叠。 | 看条纹、刀刃和细纹，不把模糊直接当作完整光学 OLPF 校准。 |
| [S21 镜头透过率](../real_sim_camera.md#S21) | 镜头对入射光的标量透过比例。 | 减小会减少到达传感器的光子，信号变弱、相对噪声更突出；不是对已经生成的 RGB 单纯压暗。 | 比较灰阶与暗部颗粒，和曝光/增益组交叉理解。 |
## 传感器：曝光与电子响应

这一组描述光子变成电子和数字码值的过程。更多光、模拟放大、数字放大和曲线提亮可能看起来相似，但物理含义不同。

| ID / 参数 | 它是什么 | 改变后影响什么 | 看图位置 |
|---|---|---|---|---|
| [E01 曝光积分亮度控制](../real_sim_camera.md#E01) | RTX exposure:time，静态曝光亮度缩放参数，单位秒。 | 增大通常更亮、较易高光截断；本原生静态组不能证明同时实现了运动积分。 | 看灰阶块与白盘细节；真实运动拖影另看 T01。 |
| [E02 ISO 亮度控制](../real_sim_camera.md#E02) | RTX 的 ISO 曝光灵敏度标尺。 | 增大通常提高输出亮度；这个渲染控制没有自动变成 AVS 的模拟增益与读噪变化。 | 看灰阶亮度和高光是否丢层次，不据此判断真实相机噪声。 |
| [E03 曝光专用 f-number](../real_sim_camera.md#E03) | 单独用于曝光计算的 f-number。 | 在其他曝光参数固定时，数值增大通常更暗，辐射缩放近似与平方倒数相关；它与几何景深光圈分开。 | 比较白盘/灰块亮度，同时核对焦外模糊没有被当作自变量。 |
| [E04 responsivity](../real_sim_camera.md#E04) | 渲染曝光模型的整体响应倍率。 | 增大通常提亮整体，并可能造成亮部截断；它是演示标尺，不是已测设备灵敏度。 | 看灰阶与水果亮部，检查最亮几级是否不再可区分。 |
| [E05 曝光补偿](../real_sim_camera.md#E05) | 相机 exposure 补偿，理论上以 stop 表示倍率。 | 理想实现中每增大 1 stop 会乘 2；本机该属性是否被管线采用必须按原图和读回核对。 | 对比灰块实际亮度，不要只看写入了哪个数字。 |
| [I22 CFA 相位](../real_sim_camera.md#I22) | 感光面上 R/G/B 滤色采样的排列相位。 | 正确配套解码时，纯色响应应相近；不同排列仍可能改变细纹的采样/伪色。 | 先看灰块是否颜色正确，再看高频条纹和彩边。 |
| [S01 量子效率 QE](../real_sim_camera.md#S01) | 量子效率：到达的光子转成有效电子的比例。 | 固定光子输入时，增大通常增加信号，降低相对散粒噪声，过大可能更早饱和；这里只是无光谱的标量。 | 同时看暗部颗粒、灰块亮度和白盘截断。 |
| [S02 入射光子数量标尺](../real_sim_camera.md#S02) | 把 renderer RGB 辐射值映射为入射光子数的标尺。 | 增大意味着模型收到更多光，信号上升且相对 Poisson 起伏减小；不是显示 RGB 后乘增益。 | 比较阴影颗粒与亮部余量，留意不是实测绝对光子数。 |
| [S03 满阱容量](../real_sim_camera.md#S03) | 像素在曝光积累阶段能容纳的最大电子数。 | 增大可保留更多电荷信号；若 ADC 先达到上限，继续增大不一定还能增加高光细节，也不必变亮。 | 看高光/白盘的层次，不只比较整图均值。 |
| [S07 模拟增益](../real_sim_camera.md#S07) | ADC 前的信号放大倍率。 | 增大会放大信号及此前噪声，也可能使 ADC 更早截断；不会增加已经收集到的光子。 | 看暗部颗粒是否跟着变大、白盘是否更早饱和。 |
| [S08 数字增益](../real_sim_camera.md#S08) | ADC 后的数字信号倍率。 | 增大让已有信号和噪声一起变大，不能找回 ADC 之前已经截断的细节。 | 同时比较灰阶、暗部颗粒和高光细节。 |
| [S09 ADC 位深](../real_sim_camera.md#S09) | ADC 量化位深，决定模拟范围内有多少码级。 | 位数增加通常减小量化步长，暗灰渐变更连续；不意味着一定变亮或提高传感器本来的信噪比。 | 看灰阶、平滑桌面渐变与暗部色带，码值附件保留实际精度。 |
| [S10 传感器黑位偏置](../real_sim_camera.md#S10) | 传感器/ADC 给数字信号加上的黑位偏置。 | 固定 BLC 扣除量时，增大偏置会抬高暗部；它不是增加有效光子。 | 看黑白靶的黑面是否发灰以及暗级灰块的间距。 |
| [S12 白电平归一化参考](../real_sim_camera.md#S12) | 电子信号归一化为满码值时使用的白电平参考。 | 增大参考值会让同一电子数对应较低输出、更大的表示余量；这不等于满阱容量真的变大。 | 看亮度变化与高光截断，把白电平映射和物理饱和分开。 |
| [S20 电子域曝光时间](../real_sim_camera.md#S20) | 在电子模型中真正用于累积光子和暗电流的曝光时间。 | 延长使信号/暗电流增加，未饱和时相对散粒噪声通常下降；本静态组不产生几何运动积分。 | 看阴影颗粒、灰阶与高光，运动效果另见 T01。 |
## 传感器：噪声、温度与缺陷

随机颗粒、固定斑点和行列条带应分开观察。这里使用明确的电子模型，参数仍是教学假设。

| ID / 参数 | 它是什么 | 改变后影响什么 | 看图位置 |
|---|---|---|---|---|
| [S04 读出噪声](../real_sim_camera.md#S04) | 读出时加入的随机电子误差，单位 e− RMS。 | 增大会使低信号区颗粒更明显；和随光子数变化的散粒噪声不同。 | 放大灰靶暗级、阴影和黑靶，结合重复帧波动。 |
| [S05 暗电流](../real_sim_camera.md#S05) | 没有光也随曝光时间积累的电子速率。 | 增大通常抬高暗信号并增加随机涨落，长曝光或高温下更明显；未扣暗时会影响黑位。 | 看黑靶、背光面与阴影，不能用自然黑物体代替真正暗场测量。 |
| [S06 温度](../real_sim_camera.md#S06) | 传感器温度，使用本实验指定的暗电流温度关系。 | 模型温度升高会增加暗电流和相应噪声；翻倍温差是演示假设，不是 AVS 实测规律。 | 比较暗部与坏点样式，先读固定暗电流上下文。 |
| [S13 PRNU 幅度](../real_sim_camera.md#S13) | 像素间固定的相对响应增益差。 | 增大后亮区更容易显出固定斑点/纹理，跨帧位置保持一致；它不是每帧都换位置的随机噪声。 | 看均匀桌面与灰块，并对照全部重复帧。 |
| [S14 DSNU 幅度](../real_sim_camera.md#S14) | 暗信号速率的像素间固定差异。 | 增大产生固定的暗信号斑驳，随模型曝光时间累积；不同于受光后才出现的 PRNU。 | 看暗部固定位置的斑点，正式量化应使用暗场序列。 |
| [S15 行相关读噪](../real_sim_camera.md#S15) | 同一行像素共享的随机读出偏移。 | 增大后容易出现横向条带或行间亮度跳动，可能逐帧变化。 | 看灰桌面和阴影里的横条，并比较重复帧。 |
| [S16 列相关读噪](../real_sim_camera.md#S16) | 同一列像素共享的随机读出偏移。 | 增大后容易出现竖向条带，和横向行噪声方向相反。 | 看灰桌面和黑靶附近的竖条纹。 |
| [S17 热像素比例](../real_sim_camera.md#S17) | 模型中被固定为高响应的异常像素比例。 | 比例增大会出现更多亮点，位置随传感器坐标固定；不是灰尘反光。 | 放大阴影与纯色区域，再看 DPC 修复组。 |
| [S18 死像素比例](../real_sim_camera.md#S18) | 模型中无正常响应的像素比例。 | 比例增大会出现更多固定暗点；去马赛克可能把它们扩成小块或带出彩色边。 | 放大白盘、亮灰块和桌面。 |
| [S19 Poisson 散粒噪声](../real_sim_camera.md#S19) | 是否启用电子域 Poisson 散粒采样。 | 开启后同输入会随机起伏；信号越高绝对波动通常越大，但相对颗粒可能更小。 | 比较暗灰块和亮灰块的重复波动，不与渲染 Monte Carlo 颗粒混为一谈。 |
## ISP：校正、颜色与细节

ISP 将传感器输入校正并重建成颜色图，再调整明暗、纹理与颗粒。每组都写明当前实现方向，避免只记滑块名称。

| ID / 参数 | 它是什么 | 改变后影响什么 | 看图位置 |
|---|---|---|---|---|
| [I01 WB 红增益](../real_sim_camera.md#I01) | 白平衡中的红通道倍率。 | 增大会增强红分量，中性物偏暖/红，红色高光也可能先截断；不会只改变红色物体。 | 先看白盘与灰块，再看甜椒和香蕉。 |
| [I02 WB 绿增益](../real_sim_camera.md#I02) | 白平衡中的绿通道倍率。 | 增大会使中性色偏绿，通道比例与亮度也可能改变。 | 看白盘是否泛绿，比较各颜色块的变化。 |
| [I03 WB 蓝增益](../real_sim_camera.md#I03) | 白平衡中的蓝通道倍率。 | 增大会使中性色偏蓝/冷，蓝通道可能更早截断。 | 先看白盘与灰块，避免只用蓝色块判断 WB。 |
| [I04 CCM 非对角混色](../real_sim_camera.md#I04) | 颜色矩阵中一组非对角项的混色幅度。 | 改变它会把别的通道加入或减出红输出，物体色相/中性响应可能变化；不是单一色温滑块。 | 比较色卡的红、绿、蓝块和水果色相。 |
| [I05 CCM 红通道系数](../real_sim_camera.md#I05) | 颜色矩阵红输出中红输入项的尺度。 | 增大增强红输入对输出的贡献，既可能改变中性块，也可能让部分颜色更饱和。 | 看红色块、白盘和灰阶是否同时改变。 |
| [I06 饱和度](../real_sim_camera.md#I06) | 把颜色相对亮度轴拉开或收拢的强度。 | 减到 0 接近灰度，增大让颜色更浓，过强可截断；它不同于电荷饱和。 | 比较甜椒、香蕉与色卡，中性块应大致仍中性。 |
| [I07 色相](../real_sim_camera.md#I07) | 在当前实现的 HSV 表达中旋转色相角。 | 正负变化会让红/黄/绿等沿色环转动，不应被理解为真实灯光光谱变化。 | 看水果从红变橙或偏紫，以及色卡各色的联动。 |
| [I08 对比度](../real_sim_camera.md#I08) | 围绕固定中灰支点拉开/压缩明暗差。 | 增大通常使亮更亮、暗更暗，可能同时丢高光和暗纹；不等于增加照明。 | 看最暗/最亮灰级是否合并，中灰是否相对稳定。 |
| [I09 亮度偏移](../real_sim_camera.md#I09) | 对处理域信号加上固定偏移。 | 增大通常抬高所有值，黑色也会发灰，和曝光乘倍率的响应不同。 | 看黑靶是否被抬起及亮处是否更易截断。 |
| [I10 gamma 指数](../real_sim_camera.md#I10) | 本实现用 x^(1/gamma) 处理，必须结合这一方向定义。 | gamma 大于 1 通常抬高中暗部，小于 1 压暗；不会增加原本丢失的动态范围。 | 看中灰和阴影的变化，不只看白盘。 |
| [I11 全局 tone map](../real_sim_camera.md#I11) | 把高动态线性输入压到显示范围的全局映射模式。 | 不同曲线改变暗部、中灰、高光分配，可能改变颜色饱和程度；线性、Reinhard 与 ACES 的响应不同。 | 看灰阶间距、高光是否压缩，以及水果颜色是否被洗淡。 |
| [I12 高光 shoulder](../real_sim_camera.md#I12) | 高光压缩曲线的膝点尺度。 | 本实现数值越小通常压缩越早/越强，数值越大更接近保留亮度；显示感觉不等于传感器动态范围变化。 | 看白盘与最亮灰块能否保留分级。 |
| [I13 局部对比度](../real_sim_camera.md#I13) | 增强局部区域相对其模糊背景的明暗差。 | 增大会加强纹理与立体感，过强可能在边缘周围出现光晕，暗噪声也可能被增强。 | 看盘沿、壶边和桌面细纹，不只看整图均值。 |
| [I14 空域降噪](../real_sim_camera.md#I14) | RGB 空域降噪的空间平滑宽度。 | 增大通常减少颗粒，但会抹去细纹与低对比边缘；干净不一定更真实。 | 同看阴影颗粒、黄瓜表面和瓶身文字。 |
| [I15 色度降噪](../real_sim_camera.md#I15) | 只对色度差异进行空间平滑的宽度。 | 增大减少彩色噪点，也可能使彩色细线/边缘变糊，而亮度细节保留相对更多。 | 比较彩色块边界与黑白条纹的区别。 |
| [I16 RAW 域平滑](../real_sim_camera.md#I16) | CFA 同相位采样上的平滑宽度。 | 增大减少 RAW 颗粒，但可能影响后续颜色重建和细纹；它发生在 demosaic 之前。 | 看水果细纹、色边和高频条纹，结合其他降噪组比较。 |
| [I17 锐化强度](../real_sim_camera.md#I17) | 高频残差叠加回图像的倍率。 | 增大让边缘更硬，也可能出现白边、黑边并放大噪声；不能恢复原来没有的细节。 | 看黑白斜边、盘沿和刀刃附近的过冲。 |
| [I18 锐化半径](../real_sim_camera.md#I18) | 提取锐化高频残差时的模糊尺度。 | 半径增大通常形成更宽的增强带/光晕，不只是“更清晰”；本组固定锐化强度。 | 看盘沿或黑白靶两侧的白边宽度。 |
| [I19 坏点修复阈值](../real_sim_camera.md#I19) | 把异常像素与同 CFA 相位邻域中值比较的门限。 | 门限降低会修复更多异常点，也更容易误改真实细节；门限高则可能留下亮点。 | 比较故意注入的热像素及细小真实纹理。 |
| [I20 镜头阴影补偿](../real_sim_camera.md#I20) | 镜头阴影补偿所采用的校正强度。 | 增大能恢复模型暗角，但会把边缘噪声也放大；过度补偿会造成反向亮角。 | 比较中心和边缘灰桌面亮度，检查边缘颗粒。 |
| [I21 去马赛克算法](../real_sim_camera.md#I21) | 从每像素一种 CFA 颜色重建完整 RGB 的算法。 | 最近邻、双线性、保边算法在平滑、锯齿和伪色之间取舍；真实分辨率没有凭空增加。 | 放大细条纹、刀刃和彩色/黑白边缘。 |
| [I23 错误 CFA 解释](../real_sim_camera.md#I23) | 是否故意用不匹配的 CFA 排列解释输入。 | 错误解释可能造成红蓝颠倒或错误颜色，不应通过调 WB 去掩盖格式错误。 | 看红、蓝色块是否被错误互换，先核对数据格式。 |

| [P02 裁剪起点 X](../real_sim_camera.md#P02) | 固定宽度 ROI 的水平起点。 | 起点向右移动会丢掉更多左侧内容；输出主点需减去裁剪起点。 | 看左侧灰块和右侧壶如何进出 ROI，不把裁剪误认为相机平移。 |
| [P03 裁剪起点 Y](../real_sim_camera.md#P03) | 固定高度 ROI 的垂直起点。 | 起点向下移动会裁掉更多上部内容；输出主点需同步变换。 | 比较色卡和盘子被保留的范围。 |
| [P04 binning 因子](../real_sim_camera.md#P04) | 把多个输入像素合成/抽取一个输出像素的边长因子。 | 因子增大通常降低输出细节；本组是已有图像上的平均/采样演示，不是电荷域 binning。 | 看输出尺寸、细条纹与小文字。 |
| [P05 binning / subsampling 模式](../real_sim_camera.md#P05) | 多像素合并采用平均、求和还是间隔抽样。 | 平均保亮度但损细节，求和在本模型中更亮易截断，抽样更容易混叠；三者不能混称同一种 binning。 | 同时看灰阶亮度、条纹与输出尺寸。 |
| [P06 插值方式](../real_sim_camera.md#P06) | 几何重采样时估计非整数坐标像素的算法。 | 最近邻更块状、双线性更平滑、三次插值可能保细节但有振铃；不会凭空增加真实分辨率。 | 放大盘沿、色块边和条纹，看锯齿与过冲。 |
| [P07 去畸变新 K 视场尺度](../real_sim_camera.md#P07) | 去畸变/虚拟相机新 K 的焦距倍率。 | 增大通常缩窄最终视场、减少边缘覆盖；减小会请求更宽射线并可能出现无效边界。 | 看边缘内容、黑边与物体像素大小。 |
| [P08 crop / resize 顺序](../real_sim_camera.md#P08) | 固定数字 ROI 与 resize 的执行顺序。 | 同一 ROI 坐标用于不同尺寸图像时代表不同视场，因此顺序改变可改变画面内容和 K。 | 看裁入的物品范围，注意 ROI 坐标属于哪一步输出。 |
| [P09 翻转](../real_sim_camera.md#P09) | 最终图像是否水平或垂直翻转。 | 翻转会改变手性/上下方向，不能靠只拷贝原 K 和外参保持几何合同。 | 看瓶子、刀与壶的位置是否左右互换或上下倒置。 |
| [P10 旋转](../real_sim_camera.md#P10) | 最终输出图旋转的角度。 | 旋转会改变坐标轴和宽高关系，必须同步变换内参和像素坐标。 | 看色卡方向与物体位置，不把它认作镜头畸变。 |
| [P11 RGB 通道解释](../real_sim_camera.md#P11) | 接收端把三个颜色通道解释为何种排列。 | 错误顺序会直接交换颜色，是格式问题；不应先用 WB/CCM 掩盖。 | 用红、绿、蓝色块快速检查，再看水果。 |
| [P12 YUV 量化范围与解码](../real_sim_camera.md#P12) | YUV full/limited 量化范围及其解码解释。 | 正确编码并正确反解时应近似一致；把 limited 当 full 会抬黑/压白、看起来发灰。 | 看最暗/最亮灰级和整体反差。 |
| [P13 YUV 编码矩阵](../real_sim_camera.md#P13) | RGB/YUV 变换采用的亮度/色差系数。 | 正确配套编码与反解应近似保持 RGB；只改变系数而两端仍匹配，不应被误解为真实色偏。 | 观察正确往返是否近似不变，再看 P14 的故意错配。 |
| [P14 YUV 错用矩阵](../real_sim_camera.md#P14) | 编码与解码使用不匹配的 YUV 矩阵。 | 错配会使特定颜色和亮度产生系统偏差，不是灯光或相机白平衡变化。 | 看红蓝色块、肤色类颜色和中性灰，和通道完全交换区分。 |
| [P15 色度子采样](../real_sim_camera.md#P15) | 色度采用 4:4:4、4:2:2 或 4:2:0 的采样密度。 | 色度采样更稀会模糊彩色细边，黑白亮度细节可能相对保留；不同于整图降分辨率。 | 比较彩色块边缘与黑白条纹的清晰度。 |
| [P16 最终量化位深](../real_sim_camera.md#P16) | 输出信号最终量化成多少个码级。 | 位深变低容易有色带和台阶；最终浏览 PNG8 不一定能展示 12bit 全部优势，码值数组另存。 | 看灰阶/桌面渐变，并查 codes 附件。 |
| [P17 JPEG 质量](../real_sim_camera.md#P17) | JPEG 有损压缩的质量设置。 | 质量越低通常块状、振铃、蚊噪和细节丢失越多，文件通常更小。 | 放大刀刃、瓶身文字、色卡边和阴影。 |
| [P18 编码器](../real_sim_camera.md#P18) | 保存/传输采用的编码器。 | PNG 为无损；此处 JPEG/WebP 使用固定演示质量但码率不同，不能仅凭同一质量数字宣称等价。 | 看细纹、边缘和暗部伪影；原始输入相同。 |
| [P19 K 的 skew](../real_sim_camera.md#P19) | 内参中把垂直坐标混入水平坐标的项。 | 正负值使图像产生相反的水平剪切，原本正交的结构变斜；不是物体运动造成的滚动快门。 | 看色卡矩形边和竖直靶是否整体剪切。 |
| [P20 rectification 旋转 R](../real_sim_camera.md#P20) | 立体矫正虚拟相机的射线旋转角。 | 改变虚拟光轴和最终视场，可能导致边缘缺失；不能只改焦距来替代这个旋转。 | 看整体视向、边界空缺和物体位置。 |
| [P21 像素中心约定偏移](../real_sim_camera.md#P21) | 两种像素中心约定之间的亚像素平移。 | 只差半个像素也会改变插值结果、边缘和细纹；普通缩略图中可能很不明显。 | 打开原尺寸放大黑白斜边与条纹，配合像素坐标理解。 |
| [P22 overscan 输入覆盖](../real_sim_camera.md#P22) | 源图是否覆盖目标需要的额外视场边缘。 | 缺失光线只能成为无效区，不能靠拉伸编造内容；本组用显式边框展示覆盖不足。 | 看新增边缘是否黑/无效，统计时应有 mask。 |
| [P23 显示编码 transfer](../real_sim_camera.md#P23) | 把线性光信号变成显示码值的编码曲线。 | 直接把 linear 当显示图通常偏暗；sRGB 与简单 gamma2.2 在暗部不同，必须配套解释。 | 看中灰/暗灰及阴影，别把编码错误当成曝光错误。 |
| [P24 输出参考白变换近似](../real_sim_camera.md#P24) | 输出参考白调整的 RGB 近似模式。 | warm/cool 改变通道比例，整体偏暖/偏冷；不等同于完整 CIE 色适应或相机光谱校准。 | 先看白盘和灰块，再比较水果色相。 |
## 光线追踪：采样与后处理

主批次使用 RTX Path Tracing，默认 32SPP、6 次反弹、去噪开启；基准/模型辐射输入为 64SPP。实时 RTX 对照也使用光线追踪。

| ID / 参数 | 它是什么 | 改变后影响什么 | 看图位置 |
|---|---|---|---|---|
| [R02 抗锯齿 / 重建模式](../real_sim_camera.md#R02) | 渲染器抑制锯齿/重建图像的模式。 | TAA/DLSS 可能平滑边缘、改变高频和时域历史；它们不是实机 ISP 模块的等价替身。 | 看斜边与条纹，模式实际支持/回退以日志为准。 |
| [R03 Path tracing samples](../real_sim_camera.md#R03) | 路径追踪每次图像积分使用的采样预算。 | 样本增加通常降低 Monte Carlo 颗粒、改善反射/阴影稳定性，但计算更慢；不会增加物理传感器光子。 | 先看阴影、光滑灰面与高光，不把低采样渲染噪声拟合成读噪。 |
| [R04 Path tracing 最大反弹](../real_sim_camera.md#R04) | 路径追踪允许的最大反弹次数。 | 次数过少可能丢间接光、反射或透射路径，甚至变黑；增加后应检查是否趋于收敛。 | 看背光面、地面反射和壶/瓶附近的间接光。 |
| [R05 Path tracing 去噪开关](../real_sim_camera.md#R05) | 是否启用路径追踪采样噪声去噪。 | 开启通常更干净，但可能抹去细纹或改变高光细节；关闭后出现的是渲染采样噪声。 | 比较阴影颗粒、黄瓜表面和刀刃，不能称为 AVS sensor 降噪。 |
| [R06 参数更新后 warm-up](../real_sim_camera.md#R06) | 修改参数后额外执行的应用预热次数。 | 预热可能让材质、历史和控制状态更稳定；当前采集还包含正式追踪步骤，不能把它简单当曝光时长。 | 看前几次重复是否漂移，并阅读逐帧设置。 |
| [R07 每次采集 render subframes](../real_sim_camera.md#R07) | 每次输出前请求的渲染子帧数。 | 可影响加载/时域累计和计算成本；Path Tracing 仍有独立 SPP 预算，子帧不等于真实快门积分。 | 看阴影与细边稳定性，结合总 SPP 与每子帧 SPP。 |
| [R08 RenderProduct 分辨率](../real_sim_camera.md#R08) | 真正的 RenderProduct 输出尺寸，本组为分辨率变量例外。 | 同视场下提高像素数会让小细节有更多采样，也改变以 px 表示的 K；并不改变真实镜头焦距。 | 打开各档原图检查 512/1024/1536 尺寸，不只看统一缩略板。 |
| [R09 渲染器](../real_sim_camera.md#R09) | 使用 RTX 实时光线追踪或 RTX Path Tracing。 | 两者都追踪光线，但间接光、反射近似、采样与去噪不同；主批次默认 Path Tracing。 | 看反射、高光、阴影与计算时间，不能将渲染器名字当作相机已标定。 |
| [R10 实时模式漫反射反弹](../real_sim_camera.md#R10) | 实时 RTX 漫反射间接光的反弹上限。 | 增加可能补足间接照明和颜色反弹；本组固定为实时光追路径，避免在 PT 中测试无关属性。 | 比较物体背光面和桌面附近反射光。 |
